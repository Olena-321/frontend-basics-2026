Шпаргалка Git команд

  1. git clone -склонувати репозіторій з GitHub
  2. git status -подивитися стан файлів у репозиторії
  3. git add – додати файл у staging area (підготувати до коміту)
  4. git commit -m "повідомлення" -зафіксувати зміни з повідомленням
  5. git push origin -відправити зміни на віддалений репозиторій
  6. git pull -підтягнути зміни з віддаленого репозиторію
  7. git branch -показати список гілок
  8. git checkout назва-гілки - переключитися на іншу гілку
  9. git checkout -b назва-гілки -створити нову гілку і одразу перейти на неї
  10. git log -об’єднати іншу гілку з поточною
  11. git mege -переглянути історію комітів

Для роботи з файлами та папками

  • cd -перейти в потрібну папку
  • ls -показати список файлів у директорії
  • ls -a -показати всі файли, включаючи приховані
